# seo-grit

> **Googleの検索結果から「おもしろい記事」が消えてどれくらい経つでしょう。**
> **大手と量産AIに埋め尽くされた検索を、現場を知る個人の手に取り戻したい。**
> **あなたの中にしかない一次情報を継続的に生産し続けること。ツールはぜんぶ無料で、すべて公開します。**

**Claude Code の上で動く、SEOメディア運営ツール。**
一次情報 × AI で「その人にしか書けない記事」を作り、WordPress への入稿・公開後の修正までを自動化します。

AIに書かせた没個性な量産記事ではなく、あなた（運営者）への壁打ちインタビューで引き出した一次情報・実体験を核に記事を組み立てる、という思想で設計されています。作者自身が自分のメディアをこのツールだけで運営しています（ドッグフーディング）。

## seo-grit は2つの部品でできています

| 部品 | 何をするか | 導入コマンド |
|---|---|---|
| **① データ基盤＋管理画面** | GSC・GA4・WordPress のデータを毎日自動収集し、診断と根拠つきの改善提案を出す。あなたの Cloudflare 無料枠で動く（**運用費¥0**） | `npx create-seo-grit` |
| **② 執筆スキル（Claude Code 用）** | 壁打ちで一次情報を引き出して記事を作り、WordPress へ入稿する | `git clone` → `install.sh`（下記） |

②だけでも使えますが、**両方入れると「データを見て書き、書いた結果をデータで確かめる」が1周つながります**。

## いまできること（v1）

- **`/grit-setup` — オンボーディング**：公式サイト・SNSのURLを読み込み、インタビューを通じて「ナレッジ（あなたの知見）」「メディア設定」「レギュレーション（トンマナ・表記ルール）」の3ファイルを生成。WordPress の接続テスト成功まで一気通貫
- **`/grit-write <キーワード>` — 記事作成**：壁打ちで一次情報を引き出す → 構成案 → 執筆 → レギュレーションチェック → デザイン（ブロック装飾・図解）付与 → アイキャッチ生成 → カテゴリ設定 → WordPress 下書き入稿まで
- **`/grit-direction` — SEOディレクション**：データ基盤（①）に接続し、「今日やるべきこと」を根拠の数値つきで提示。合意 → リライト等の実行 → PDCA台帳への記録 → 効果測定日が来たらツール側から声かけ。熟成中の記事（公開90日未満）には提案しない等のガードレール内蔵
- **公開後の修正**：WP側を正本として、現在の本文を取得（pull）→ 修正 → 書き戻し。管理画面での手直しを消さない設計
- **事故防止の作り込み**：スラッグ重複の検知／記事フォルダとWP記事のID対応管理／カテゴリ台帳（AIが勝手にカテゴリを作らない）

## 必要なもの（事前にインストール）

| 項目 | バージョン | 備考 |
|---|---|---|
| **WordPress サイト** | ✅ 5.6以上 | アプリケーションパスワードが使えること（サイト構築自体はスコープ外） |
| **[Claude Code](https://claude.com/claude-code)** | ✅ 最新版 | ②の執筆スキルの実行環境。`claude --version` で確認、無ければ公式サイトの手順でインストール（有料。ツール自体は無料ですが Claude の利用料がかかります） |
| **[Node.js](https://nodejs.org/ja)** | ✅ 22以上 | ①のデータ基盤に必要。`node -v` で確認、無ければLTS版をインストール |
| **python3** | ✅ 3.9以上 | アイキャッチ生成に使用（Macは最初から入っています） |

バージョン確認が不安な方は、Claude Code に「このREADMEのセットアップをやって」と頼めば、確認からインストールまで代わりにやってくれます。

## セットアップ

コマンドはすべて**ターミナル**（Macなら「ターミナル」アプリ、Windowsなら PowerShell）に貼り付けて Enter で実行します。

### ① データ基盤＋管理画面（約30分・クレジットカード不要）

ターミナルで以下を実行します：

```bash
npx create-seo-grit
```

ウィザードが1ステップずつ案内します（Cloudflareログイン → 自動デプロイ → WordPress接続 →
Google接続の伴走 → 初回データ収集）。途中でやめても再実行で続きから再開します。
必要なもの: [Cloudflareアカウント](https://dash.cloudflare.com/sign-up)（無料）・
GSC / GA4 のプロパティ所有者である Google アカウント。

完了すると管理画面のURLと、Claude Code との接続コマンド（MCP）が表示されます。

### ② 執筆スキル（約10分）

ターミナルで以下を実行すると、スキルが Claude Code に登録されます：

```bash
git clone https://github.com/hayarabo/seo-grit.git && seo-grit/scripts/install.sh
```

あとは作業フォルダを作り、そこで Claude Code を起動するだけです。続けてターミナルで：

```bash
mkdir -p ~/my-media && cd ~/my-media   # 作業フォルダ（場所と名前は自由）
claude                                 # そこで Claude Code を起動
```

起動した Claude Code の中で、次のコマンドを使います：

1. `/grit-setup` — 初回のみ。質問に答えていけば WordPress 接続まで完了します
2. `/grit-write 狙いたいキーワード` — 記事作成。キーワード省略時はナレッジから記事案を提案します
3. `/grit-direction` — データが貯まり始めたら（①導入後）。「ディレクションして」でも起動します

## 仕組み：リポジトリには「仕組みだけ」が入っています

```
skills/      スキル定義（Claude Code から呼び出すプロンプト資産）
scripts/     実行スクリプト（WordPress REST API での入稿・取得・画像アップロードなど）
templates/   作業フォルダに生成されるユーザーデータファイルの雛形
docs/        設計資料（決定事項のみ）
```

あなたのデータ（ナレッジ・レギュレーション・WP接続情報・記事原稿）はすべて**作業フォルダ**（このリポジトリの外）に生成され、リポジトリには一切入りません。接続情報は作業フォルダの `.env` にのみ置かれます。

## ロードマップ：SEOディレクションOSへ

目指しているのは **SEOメディア運営のディレクションOS** です。GSC・GA4・WordPress のデータを蓄積し、「今日は何をやるべきか」の優先順位を、根拠の数値と見込み効果つきで提示するところまで（設計資料: [docs/data-spec.md](docs/data-spec.md)）。

| フェーズ | できるようになること | 状態 |
|---|---|---|
| **P1** | GSC・GA4・WPのデータを日次で自動蓄積（GCP初期設定は伴走ウィザード付き）。APIの保持期間に縛られない自前の定点データ | ✅ **v0.1 で提供中**（`npx create-seo-grit`） |
| **P1.5** | 蓄積データによる記事診断と処方箋——リライト／タイトル改善／内部リンク／新規記事／技術修正——を根拠数値・見込み効果つきで提示。PDCA台帳・効果測定日の声かけ。管理画面・クエリ順位トラッキング・AI経由流入の計測 | ✅ **v0.1 で提供中**（統合・削除・CV改善の処方箋は下記P2以降） |
| **P2** | GA4のキーイベント（LINE登録・問い合わせ等のCV）接続。優先順位づけが「SEO順位ベース」から**「売上ベース」**に切り替わる | 予定 |
| **P3** | 外部キーワードAPIによる新規機会の発掘・競合分析／AI引用の本格モニタリング | 予定 |

全体設計: [docs/architecture.md](docs/architecture.md)

## 料金の正直な話（¥0って本当？）

本当です。データ基盤はあなた自身の Cloudflare アカウントの**無料枠**で動き、
個人〜中規模メディアなら枠に収まるように設計してあります。

| Cloudflare無料枠（執筆時点の公称） | seo-grit の消費（記事数十本規模の実測感） |
|---|---|
| リクエスト 10万/日 | 毎朝の自動収集1回＋管理画面の閲覧＝**数百/日** |
| D1 書き込み 10万行/日 | 日次収集で**数十〜数百行/日** |
| D1 保存容量 5GB | 1日2,000行貯めても**年間約0.1GB** |

有料プラン（月$5〜）が視野に入るのは、**月間数百万表示クラスの大規模メディア**が
検索クエリデータを貯め続けた場合の書き込み上限くらいです。その規模でも壊れはしません——
収集は中断・再開設計なので、上限に当たった分は翌日自動で続きから取り込まれます。

このほか実費として、Claude Code（執筆・壁打ちに使用）の利用料は別途かかります。
ツール自体・データ基盤・管理画面は無料です。

## 正直な注意点

- **meta description**：抜粋（excerpt）に書き込みますが、それを meta description として出力するかはテーマ・SEOプラグイン側の設定に依存します
- **サイトのセキュリティ設定**：CSP 等を厳しくしているサイトでは、画像やスクリプトの表示に個別対応が必要な場合があります
- **記事の品質は一次情報の質に比例します**：壁打ちで答える中身が薄いと、記事も薄くなります。ツールは「知見を記事にする」道具であって、知見そのものは作れません
- 開発途中のプロダクトです。不具合・要望は [Issues](https://github.com/hayarabo/seo-grit/issues) へどうぞ
